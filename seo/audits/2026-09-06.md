### Reading the data

- **Volume is thin** (245 impressions / ~6.5 weeks ≈ 5/day). At this volume,
  0% CTR on most individual queries is not yet a meaningful signal — most rows
  have 1–2 impressions, too few to judge snippet quality. Don't rewrite
  title/meta off this data yet; the homepage title/description already target
  "AI Photo Booth Singapore" and read as compelling on manual review.
- **"photobooth" (one word) dominates real query volume** — near me,
  chinatown, chinatown point, tanjong pagar, 24 hour, nearby — far more than
  any of the playbook's target two-word phrases ("photo booth Singapore"
  etc.). The two-word copy fix (iteration 4) targets a phrase real searchers
  aren't typing as much as expected in this window. Worth continued tracking,
  not a reversal — two-word "photo booth" is still the higher-intent phrase
  Google itself associates with the vertical, and copy already covers both
  forms.
- **Heavy local/neighborhood intent**: "chinatown", "tanjong pagar", "maxwell"
  appear repeatedly. This site has no location-specific content and no Google
  Business Profile — local-pack results (which is what these near-me queries
  actually surface) come from GBP, not organic ranking. This is the single
  strongest data-backed argument for the still-outstanding **JEFF: Google
  Business Profile** backlog item — it directly matches demonstrated search
  intent, not a guess.
- **"phoyo"** (19 impressions, position 6.0) is very likely a typo/fragment of
  "photo" — low actionability, ignore.
- Zero clicks total is consistent with average position ~7.7 (bottom of page
  1 / top of page 2) at this impression volume — expected, not alarming yet.

## 2. Indexing status — found and fixed a real gap

Checked Indexing → Pages: **1 page indexed, 4 excluded.** Drilled into all 4:

| Reason | Pages | Verdict |
|---|---|---|
| Page with redirect | 2 | `http://` versions of root — correct, HTTP→HTTPS is intended |
| Alternate page with proper canonical tag | 1 | `https://www.playingwithphoto.com/` — correct, canonicalizes to apex domain as designed |
| Discovered - currently not indexed | 1 | `https://playingwithphoto.com/software/` — **not expected, real gap** |

`/software/` is a real, live page (photo booth software waitlist — the
productization plan) with `meta robots: index, follow`, linked from the
homepage nav, and present in `sitemap.xml` (`lastmod` 2026-07-28). Google's
URL Inspection tool nonetheless reported "No referring sitemaps detected" /
"Referring page: None detected" for it — likely a stale crawl of an older
sitemap fetch, not a real problem with the page.

**Action taken:** used URL Inspection → Request Indexing. Google confirmed
"Indexing requested — URL was added to a priority crawl queue." No code
change needed; this is a one-time nudge, not a recurring fix.
